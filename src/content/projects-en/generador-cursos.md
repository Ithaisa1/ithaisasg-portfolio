## Try it

The [demo](/demos/generador-cursos/) has two example courses. **Start with the web accessibility one**: it walks you from a few documents to the finished course.

1. Three documents are already uploaded and read (a Markdown guide, a Word checklist and a PDF sheet).
2. Press **Proponer índice** ("Suggest outline"): the AI decides modules and lessons and which parts of your documents each one uses.
3. **Approve the outline**. Nothing is written until you do.
4. The content is written: every block says whether it is *extracted*, *reworded* or an *AI addition*, and which file and passage it comes from, with the literal quote when there is one.

The other course (Git and GitHub) was generated from scratch, without documents. In the **Exportar** ("Export") tab you can download both in the 9 real formats.

This is a demo: the result of each step is always the same, nothing is saved and no AI is called. The example courses were written by an AI (Gemini) and no expert has reviewed them; the demo itself says so. The interface is in Spanish.

## The problem

Preparing a Moodle course takes hours. And when AI helps, it is hard to tell which parts come from your materials and which the model made up, which matters if the course is going to be given to students.

## Technical decisions

- **Sources are checked by code, not by the AI.** The AI proposes which passage each block comes from; the code verifies that it exists, that a "literal" quote really appears in the passage, and downgrades to "reworded" or "AI addition" whatever does not hold up. In "documents only" mode, anything without a source is discarded.
- **The outline is approved before any AI is spent on the content**, and each lesson receives only its own passages.
- **Safe document reading:** the file type is detected from its content, ZIP files are inspected, and each file is read in a separate process with limited memory and time. The document text goes to the AI marked as data, never as instructions, and the AI has no tools.
- **Own Moodle exporter** (`.mbz` for 4.5 and 5.3, plus question XML) checked by restoring it in a real Moodle, along with SCORM 1.2, web, Markdown, Word, PDF and PowerPoint.
- **Editor with version control:** autosave, per-piece history, restoring versions and a warning if the course changed in another tab.
- **Accounts and security:** scrypt passwords, server-side sessions, CSRF protection, email confirmation and password recovery.
- **Demo built from the same code:** a build switch replaces the API with saved data, without maintaining two versions. Almost 300 automated tests, plus walkthroughs checked in a real browser.

## Limits worth knowing

- It does not read scanned PDFs (no OCR) and detects PDF headings only approximately.
- I have not evaluated the teaching quality of what it generates, and no expert reviews the courses.
- The full version needs a server with a database and an AI key; the demo does not.
